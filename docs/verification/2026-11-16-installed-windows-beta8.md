## 发现并修复的问题

长间隔健康判断仍固定为 40 分钟。独立空白 PostgreSQL 的 HTTP 回归复现：组织配置 180–1440 分钟，60 分钟前的报告被错误计为较旧。

修正为组织最长同步间隔加 5 分钟缓冲，并保留兼容旧客户端所需的至少 40 分钟判断窗口。回归同时覆盖最长间隔后 4/6 分钟、短策略下报告年龄 39/41 分钟，以及策略恢复后的判断。更新看板文案、OpenAPI 描述和新鲜度说明；没有改写已部署数据库迁移。
